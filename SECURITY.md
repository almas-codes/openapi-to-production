# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `openapi-to-production` (`o2p`), please send an email to almaskhanwazir@gmail.com. All security vulnerabilities will be addressed promptly.
